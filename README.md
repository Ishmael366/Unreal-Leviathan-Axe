# Leviathan Axe Throw & Recall

An Unreal Engine Blueprint mechanic for aiming, throwing, sticking an axe to a surface, and recalling it to the character.

![Axe throw and recall preview](Imgs%20%26%20GIFs/GodOfWarAxeMechanicGIF.gif)

## Features

- Aim and throw interaction
- Surface impact and attachment
- Recall during flight or after impact
- Character-hand attachment and animation setup
